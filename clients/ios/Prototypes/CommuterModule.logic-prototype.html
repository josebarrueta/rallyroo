Commuter module lifecycle

This throwaway prototype asks: Can Rallyroo enable an optional Caltrain capability, subscribe a family to a commute, handle provider outages, and remove the capability—without treating live transit data as Family Events?

Assumption: “Install” enables code already shipped with Rallyroo. iOS does not download or execute third-party module code. Rallyroo’s backend holds the 511 key, caches static GTFS configuration, polls shared real-time feeds, and sends only matched results to the app.
